# 블룸캠 (BloomCam) 📷✨
> **갤럭시 기본 카메라의 과도한 선명함을 지워주는 감성 뽀샤시 무음 카메라 & 피규어/건프라 전문 촬영 앱**

갤럭시 기본 카메라 특유의 과도한 샤프닝(모공, 잔주름, 피부 요철 부각)을 부드럽게 지워주는 **사진관급 뽀샤시 무음 카메라**이자, 플라스틱 번들거림을 억제하고 먹선(패널라인)을 날카롭게 살려주는 **피규어·건프라 전용 모델러 촬영 모드**를 지원하는 올인원 카메라 애플리케이션입니다.

---

## 📱 주요 핵심 기능

### 1. 🔕 100% 무음 셔터 (Silent Shutter)
- 공공장소, 조용한 카페, 독서실, 식당, 피규어 전시회에서도 부담스러운 **"찰칵!" 소리 없이 100% 조용하게 촬영**할 수 있습니다.
- CameraX 로우 레벨 메모리 캡처 파이프라인으로 안드로이드 시스템 강제 셔터 효과음을 완전히 차단했습니다.

### 2. 🎯 3가지 맞춤 촬영 모드 (Camera Modes)
하단 모드 선택 휠을 통해 피사체에 최적화된 엔진으로 원터치 전환할 수 있습니다:
1. **🌸 인물 모드 (Portrait)**
   - 갤럭시 카메라의 과도한 모공/요철 부각을 자연스럽게 완화하는 **도자기 피부 스무딩 + 핑크/피치 톤업 + 사진관 스튜디오 45도 조명 입체감**.
   - 프리셋: `퓨어 블룸`, `사진관 프로필`, `피치 글로우`, `웜 크림`, `소프트 무드`, `체리 블라썸`, `필름 감성`, `원본`
2. **☕ 사물 / 일상 모드 (Object)**
   - 카페 소품, 디저트, 음식, 풍경의 색감을 먹음직스럽고 생생하게 살려주는 채도 & 선명도 최적화.
   - 프리셋: `비비드 팝`, `카페 감성`, `푸드 딜라이트`, `클린 미니멀`, `원본`
3. **🤖 피규어 / 건프라 전용 모드 (Figure & Gunpla)**
   - **일반 사물 모드와의 결정적 차이점**:
     - **플라스틱 사출 번들거림 억제 (Anti-Glare Matte)**: 조명 아래에서 하얗게 날아가는 플라스틱 표면 하이라이트를 차분하게 눌러주어 무광 탑코트(마감제)를 올린 듯한 고급스러운 질감 연출.
     - **패널라인(먹선) & 몰드 엣지 초정밀 강화 (Unsharp Mask)**: 미세한 먹선, 메카닉 단차, 각진 모서리를 뭉개짐 없이 날카롭고 또렷하게 부각.
     - **피사체 집중 스튜디오 비네팅**: 주변부 조명을 은은하게 정돈하여 피규어/건프라 본체에 시선이 꽂히는 박스아트 화보 느낌 구현.
   - 프리셋: `먹선 & 메카닉`, `무광 마감 (매트)`, `메탈릭 헤비`, `박스아트 화보`, `미소녀 피규어`, `원본`

### 3. 🛠️ 사진관 & 모델러 전문 정밀 리터칭 패널 (Studio Retouch)
촬영 직후 또는 사진 확인 화면에서 전문 도구 슬라이더로 1% 단위 세부 조정이 가능합니다:
- **피부결 도자기 스무딩 (0% ~ 100%)**: 모공과 잡티를 깨끗하게 정돈
- **먹선·몰드 선명도 (0.0x ~ 2.0x)**: 건프라 패널라인과 디테일을 날카롭게 부각
- **스튜디오 45도 조명 (0% ~ 100%)**: 소프트박스 반사판을 비춘 듯한 입체 하이라이트
- **무광 마감 (0% ~ 100%)**: 플라스틱 반사광 번들거림 억제

### 4. 🎚️ 실시간 필터 강도 조절 (0% ~ 100%)
- 뷰파인더에서 실시간으로 틴트와 뽀샤시 농도를 조절하며 미리 확인 후 촬영 가능.

### 5. 🔄 전면 셀카 좌우 반전 방지 & 터치 초점
- 전면 카메라 촬영 시 거울로 보던 내 모습 그대로 자연스럽게 저장.
- 화면 터치 시 골드 포커스 링 애니메이션과 함께 정확한 자동 초점 조절.

### 6. 📐 다양한 화각 비율 (4:3, 16:9, 1:1 정방형)
- 상단 원터치 버튼으로 인스타그램용 정방형 1:1부터 시네마틱 16:9까지 즉시 전환.

## 🛠️ 기술 스택 및 아키텍처
- **Language**: Kotlin 1.9.23
- **UI Toolkit**: Jetpack Compose (Material3)
- **Camera Pipeline**: AndroidX CameraX 1.3.3 (`camera-core`, `camera-camera2`, `camera-lifecycle`, `camera-view`)
- **Image Processing Engine**: 
  - `fastBoxBlur` 듀얼 블렌딩 피부 스무딩
  - `Unsharp Mask` 패널라인/엣지 고주파 강화 필터
  - `Anti-Glare` 하이라이트 감쇠 무광 질감 엔진
  - `RadialGradient` 스튜디오 45도 조명 및 비네팅
- **CI/CD**: GitHub Actions (자동 APK 빌드 및 아티팩트 배포)

---

## 🚀 GitHub Actions를 통한 최신 APK 다운로드 방법

1. 저장소 상단의 **[Actions]** 탭으로 이동합니다.
2. 최신 실행된 워크플로우(초록색 체크 ✔ 표시)를 클릭합니다.
3. 페이지 하단의 **Artifacts (아티팩트)** 섹션에서 **`BloomCam-Debug-APK`**를 다운로드합니다.
4. 다운로드된 ZIP 파일의 압축을 풀고 스마트폰에 `app-debug.apk`를 설치하시면 됩니다!
