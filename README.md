# 블룸캠 (BloomCam) 🌸✨
> **갤럭시 기본 카메라의 과도한 선명함을 부드럽게 지워주는 감성 뽀샤시 무음 카메라 앱**

갤럭시 기본 카메라 특유의 과도한 샤프닝(모공, 잔주름, 피부 요철 부각)을 자연스럽게 보완하여, 거울을 보는 것처럼 부드럽고 화사한 피부 톤을 연출해 주는 **초경량 뽀샤시 무음 카메라** 애플리케이션입니다.

---

## 📱 주요 핵심 기능

### 1. 🔕 100% 무음 셔터 (Silent Shutter)
- 공공장소, 조용한 카페, 독서실, 식당에서도 부담스러운 **"찰칵!" 셔터 소리 없이 조용하고 편안하게 촬영**할 수 있습니다.
- CameraX 로우 레벨 캡처 파이프라인을 채택하여 불필요한 시스템 셔터 효과음을 완전히 차단했습니다.

### 2. 🌸 7가지 뽀샤시 & 감성 필터 프리셋
1. **퓨어 블룸 (Pure Bloom)**: 맑고 투명하며 화사한 투명 피부 연출
2. **피치 글로우 (Peach Glow)**: 노란기/붉은기를 완화하고 생기 넘치는 복숭아빛 톤
3. **웜 크림 (Warm Cream)**: 따스하고 포근한 우유빛 카페 감성
4. **소프트 무드 (Soft Mood)**: 피부 잡티를 부드럽게 감싸주는 몽환적인 소프트 글로우
5. **체리 블라썸 (Cherry Blossom)**: 봄날 벚꽃잎처럼 사랑스럽고 화사한 핑크 톤
6. **필름 감성 (Vintage Film)**: 레트로하고 아늑한 색감의 아날로그 필름 룩
7. **RAW (원본)**: 필터 없는 일반 자연스러운 촬영

### 3. 🎚️ 실시간 뽀샤시 강도 조절 (0% ~ 100%)
- 너무 과하지도, 너무 밋밋하지도 않게 슬라이더를 통해 내 피부와 조명에 딱 맞는 뽀샤시 농도를 1% 단위로 자유롭게 조절할 수 있습니다.

### 4. 🔄 전면 셀카 & 자연스러운 거울 모드
- 셀카 촬영 시 좌우가 어색하게 뒤집히는 현상 없이, 화면에서 보던 예쁜 내 모습 그대로 저장됩니다.

### 5. 📐 다양한 촬영 비율 (4:3, 16:9, 1:1)
- 인스타그램 감성의 1:1 정사각 비율부터 와이드 16:9, 표준 4:3 비율까지 상단 버튼 하나로 빠르게 전환할 수 있습니다.

### 6. 📁 표준 갤러리 자동 저장 (`Pictures/BloomCam`)
- 촬영된 사진은 기기 갤러리의 `BloomCam` 전용 앨범에 고화질 JPEG로 즉시 저장되며, 촬영 직후 좌측 하단 썸네일 버튼을 통해 바로 확인할 수 있습니다.

## 🛠️ 기술 스택 및 아키텍처
- **Language**: Kotlin 1.9.23
- **UI Toolkit**: Jetpack Compose (Material3)
- **Camera Pipeline**: AndroidX CameraX 1.3.3 (`camera-core`, `camera-camera2`, `camera-lifecycle`, `camera-view`)
- **Image Processing Engine**: 커스텀 소프트 스킨 스무딩 및 톤 그레이딩 엔진 (`PhotoFilterEngine`)
- **Image Loading**: Coil 2.6.0
- **CI/CD**: GitHub Actions (자동 APK 빌드 및 아티팩트 배포)

---

## 🚀 GitHub Actions를 통한 최신 APK 다운로드 방법

1. 저장소 상단의 **[Actions]** 탭으로 이동합니다.
2. 최신 실행된 워크플로우(초록색 체크 ✔ 표시)를 클릭합니다.
3. 페이지 하단의 **Artifacts (아티팩트)** 섹션에서 **`BloomCam-Debug-APK`**를 다운로드합니다.
4. 다운로드된 ZIP 파일의 압축을 풀고 스마트폰에 `app-debug.apk`를 설치하시면 됩니다!
